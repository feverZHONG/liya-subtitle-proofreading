# 字幕处理通用坑

> 2026-09-28 从 SKILL.md 拆出，内容一条未删。双坐标系／插值／硬切／碎尾这些是**重建模式**的深坑，对照校对也适用。

---

## 坑


- 字幕是口语化转写，天然比原文短 10-20%（标点、虚词、重复省略）——差异多是正常的，别当漏句
- 「delete」差异块常是 SequenceMatcher 对齐伪影（替换块挪位），先看相邻 replace 再定论
- 时间轴重叠/序号缺失是格式问题，跟文本错字分开报
- 大批量（千块级）字幕别手改，脚本跑：解析→diff→定位→替换表→验证，一次成型
- **双坐标系陷阱（重建模式最深的坑）**：规范化后文本位置 ≠ 原始文本位置（去标点、数字转中文会让字符数变）。映射表（cmap）索引基于**规范化**文本，切片必须经 `raw_positions`（规范化字符→原始位置）转回原始坐标，否则取出来的片段全错位
- **开区间终点别 +1**：`txt_slice` 的 r1 = `raw_positions[t1]`（不含 t1 位置字符），+1 会让每块末尾多吞下一块的第一个字
- **cmap 末尾补赋值**：`cmap[len(sub_norm)]` 要显式指向原文末尾，否则是 0/None，末尾块会切到文件尾或原文开头
- **脚本输出别覆盖输入**：重建脚本把「校对版」写到原 SRT 路径后，二次运行会读到中间产物（块数已变），映射全乱——始终用原始 SRT 做输入基准
- 英文副型标题（Self-Preservation/Social/One-to-One Sexual）在原文里就有，重建后保留是正常的，别当异常删
- **findall 切出孤立右引号**：`re.findall(r'[^。！？；，、]+[。！？；，、]?')` 的分割符集不含引号，会把句尾「”」切成独立段 → 纯标点段（无汉字/字母/数字）在拆分循环里**直接并入前段**，不触发长度判断
- **硬切切掉结尾句号**：23 字符句（含引号+句号）在 22 处硬切 → 22 字段缺句号 + 1 字「。」单独块。硬切前算 `rest = cur[cut_at:]`，`len(rest) ≤ 4` 且 `len(cur) ≤ MAXLEN+6` 则 break 整段保留
- **碎尾合并污染章节标题**：前段 <8 字并入后段时若后段是标题 → 标题被加前缀（如「”第一层：外在行为…」）。refined 合并条件必须加 `not is_heading(text)`；标题识别正则定义要提前（第 3 步就要用）
- **块长判断用原始长度**：判断/统计统一 `len(text)`（原始含标点），别用规范长度——「“我不是想挑剔，…视而不见。”」规范 23 字、原始 28 字，用错标准会漏拆
- **时间轴分配用插值**：单元起点落在前一块区间内时，「取第一个重叠块的 start」会让相邻两块 start 相同。用 `t_at(u)`：u 在覆盖它的原字幕块内 `start + (u-a0)/(a1-a0)*(end-start)` 插值，输出无缝衔接
